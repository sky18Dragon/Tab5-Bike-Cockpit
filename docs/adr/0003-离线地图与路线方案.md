# ADR-0003 离线地图与路线:`map_tiles` v2 + OfflineMapDownloader

- 状态:已接受(2026-10-16)

## 背景

产品文档需要:离线瓦片地图、GPS 跟随、缩放拖动(P0);离线路线与转向播报、在线规划(P1)。原技术方案草案里自定了 `route.bin` 格式和 `tools/map-export` 工具。调研发现 `0015/map_tiles` 2.0.0 已提供完整的导航层,并有配套 PC 工具。

## 备选

| 方案 | 说明 |
| --- | --- |
| A. `map_tiles` v2 + OfflineMapDownloader | 用组件的 `map_view` / `map_route` / `map_tile_cache`;PC 端用其 `app_nav.py` 生成瓦片与 `route.bin` |
| B. `map_tiles` v1 + 自研路线与缓存 | v1 只提供固定格网,同步加载;路线匹配、偏航、转向都要自己写 |
| C. 完全自研 | 瓦片缓存、地图渲染、路线匹配全自研 |

## 决策

选 A。

- 不自定义 `route.bin`,采用组件格式
- `tools/map-export/` 只放使用说明和封装脚本,不复制第三方代码
- 离线路线由 PC 端规划(OSRM / Valhalla,含骑行档);在线规划在设备端把结果转成同一格式的 `route.bin` 再加载,线上线下共用渲染 / 匹配 / 播报链路
- 数据源遵守其使用条款:不用公共 OSM 瓦片服务器批量下载;使用允许离线使用的源(例如 Geoapify 免费档,须保留署名)
- 坐标统一用 WGS-84;接入高德等 GCJ-02 数据时在设备端转换

## 后果

- 依赖第三方组件与工具的版本;`map_tiles` 锁 2.0.x,工具记录所用提交
- 「跟随车头」转图不在组件接口内,单列为 M3 实验项(PPA 旋转),不满足帧率则只旋转车标
- 需要一个 C 版 `route.bin` 写入器(M4),格式以 `map_route.h` 为准
- 缓存槽数、同屏瓦片数要实测,基线 48 槽(6MB)
- 地图数据的授权与署名成为发布前检查项(R8)
