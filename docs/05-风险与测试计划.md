## 3. 测试策略

分四层:

| 层 | 对象 | 方式 | 工具 |
| --- | --- | --- | --- |
| 单元(host) | NMEA 解析、route.bin 读写与校验、Safety 迟滞、焦点状态机、路线下一转向计算 | 在电脑上编译运行纯 C/C++ 逻辑 | Unity / GoogleTest(任选其一),CI 可跑 |
| 台架(硬件) | 屏幕触摸、音频录放、Wi-Fi 重连、SD 读写、GPS 串口、BLE 配对 | 固件内诊断菜单或脚本;模拟 NMEA 回放 | 串口日志、NMEA 回放文件 |
| 集成 | MCP 工具链路、焦点切换、App 生命周期、断网降级 | 语音脚本 + 手工清单 | 清单 |
| 实车 | 定位、地图、唤醒、可读性、续航、防护 | 实际骑行 | 实车清单 + 日志 |

### 3.1 单元测试要点

- NMEA:校验和错误、无效定位、字段缺失、跨行粘包、速度尖峰
- Safety:速度在阈值附近抖动时不频繁切换;信号丢失时的默认状态(建议保持上一状态 + 超时后按 `RIDING` 处理,避免误开放游戏)
- 焦点:小智与导航播报同时到达、连续对话、音乐暂停时的恢复
- route.bin:CRC 错误、点数 0、转向索引越界

### 3.2 NMEA 回放

录制一次真实骑行的 NMEA 日志存入 `tools/` 之外的测试数据目录(不含个人住址附近的数据;如需入库先抹去或平移坐标),台架上通过 UART 或软件注入回放,用于:

- 地图跟随与帧率回归
- Safety 闸门
- 路线偏航与转向提示

### 3.3 台架清单(每个里程碑回归)

- [ ] 启动日志核对屏幕为 ST7121、触摸地址 0x55(与机器版本一致)
- [ ] 打开 `EXT5V_EN` 后 GPS 有电并输出 NMEA;关闭后断电
- [ ] 读取 C6 固件版本并记录
- [ ] 冷启动到桌面 ≤ 5s;到可唤醒 ≤ 10s
- [ ] 热点断开 / 恢复后自动重连;C6 复位后重连
- [ ] SD 卡拔插:提示 Toast,App 不崩溃
- [ ] 音乐播放中唤醒小智,音乐压低,结束后恢复
- [ ] 无网络:导航、本地音乐可用;小智提示无网络
- [ ] 连续运行 2 小时,堆水位无持续下降

## 4. 实车测试清单

每次实车骑行记录:日期、天气、路线、硬件状态、固件版本、问题。

| 项 | 方法 | 通过标准 |
| --- | --- | --- |
| 定位 | 开机冷启动,骑行 30 分钟 | 冷启动可定位;全程不丢;丢失 3 秒内提示 |
| 地图 | 跟随与拖动 | ≥ 20fps,瓦片缺失显示占位图不卡 |
| 唤醒 | 不同速度、不同路面各 20 次 | 唤醒率 ≥ 静止时的 70%;响应 ≤ 500ms |
| 语音可听 | 内置扬声器,各音量档 | 找到有效音量上限;记录是否需要 EQ |
| 可读性 | 正午、逆光、阴天 | 转向 / 距离 / 速度一眼可读 |
| 触控 | 戴手套 | 96px 目标可靠触发 |
| 安全闸门 | 骑行中尝试进游戏、输入密码 | 均被拒绝并提示 |
| 续航 | 导航 + 音乐连续运行 | 记录时长,目标 ≥ 3 小时 |
| 防护 | 颠簸路面、小雨 | SD 卡与 GPS 线不松脱,无进水 |
| 温度 | 夏季日晒、冬季低温各一次;记录外壳内温度 | 过热降背光并提示;记录是否超过 0–40°C 并写入使用说明 |
| 电池 | 放电到低电量告警与自动关机 | 电压远高于 6V 时完成关机;关机后能正常充电恢复 |
| 坐标 | 在线规划路线叠加到地图 | 与实际道路偏差 < 10m(验证 GCJ-02 → WGS-84 转换) |

## 5. 缺陷管理

- 严重度:S1 影响行车安全或数据丢失;S2 主要功能不可用;S3 次要功能 / 体验;S4 优化
- S1 必须在进入下一里程碑前关闭;S2 允许带到下一里程碑但需记录原因
- 缺陷记录位置:仓库 Issues(上 GitHub 后)或 `docs/bugs.md`(本地)
