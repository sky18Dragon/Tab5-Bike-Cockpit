来源:《Tab5 智能车机 · 产品功能设计文档》。本文把它整理成可追踪的需求条目,每条带编号,方便在任务、测试和提交中引用。

优先级:P0 = 能上车用的最小版本;P1 = 补齐体验;P2 = 扩展。

## 2. 模块需求

### 2.1 桌面 / Launcher(SYS-01)

- 横屏 1280×720;左侧常驻 Dock(导航、音乐、小智、游戏、设置),右侧卡片区
- 状态栏:时间、Wi-Fi 信号、GPS 定位状态、BLE 连接、音量、电量/外部供电
- 卡片:迷你地图(当前位置 + 下一转向)、正在播放(封面、曲名、播放/暂停)、小智状态
- 交互:点 Dock 进入 App;任意 App 中从左边缘右滑,或说「回到桌面」返回
- 音乐与导航可后台运行,桌面卡片和状态栏实时显示其状态

### 2.2 小智语音助手(XZ-01)

小智是常驻后台的系统服务,不是普通 App,任何界面下都能唤醒。

- 唤醒:本地唤醒词「你好小智」,也可点 Dock 图标;ES7210 双麦 + AEC,音乐播放时也能唤醒
- 对话浮层:半透明叠在当前 App 上方,显示识别文字、回复文字和表情;导航时浮层只占屏幕下方 1/3
- 打断:小智说话时可再次唤醒打断
- 能力:各 App 把操作注册为 MCP 工具(见第 3 节)
- 离线降级:断网时提示「当前无网络」,本地 App 不受影响
- 配置:设置页可填小智服务地址并激活设备(沿用官方激活流程)

### 2.3 导航(NAV-01/02/03)

- 地图:使用 `0015/map_tiles` v2(`map_view`)读取 SD 卡上的 RGB565 256×256 瓦片(`{z}/{x}/{y}.bin`,每块约 128KiB);用户用电脑工具(OfflineMapDownloader)预先导出常骑区域的若干缩放级别
- 定位:Unit GPS v1.1(AT6668,多系统联合定位),经 Tab5 的 PORT.A 口(G53 / G54)UART 115200 8N1,NMEA0183;默认 1Hz,可配 5–10Hz;P0 支持「北向上」+ 车标按航向旋转,「跟随车头」(地图转向)为实验项,帧率不达 20fps 则不做(见 06 的 T5)
- 安装:GPS 天线面朝上固定在车把或车头,避免被手、手机或金属遮挡;冷启动约 23 秒,上车后先显示上次位置
- 操作:双指缩放、拖动;拖动后 10 秒无操作自动回到跟随模式
- 路线(P1):加载离线 `route.bin`(`map_route` 格式,由电脑端工具或 GPX 生成),画路线,显示下一转向和距离,偏航时提示回归方向,小智语音播报
- 在线规划(P1):「导航到 XX」时小智经 MCP 调用设备侧导航工具;路径由在线地图 Web API(高德骑行或 Valhalla)计算,返回折线后转为 WGS-84 并在本地生成 `route.bin` 再绘制
- 无 GPS 信号:显示「等待定位」,保留上次位置

### 2.4 音乐(MUS-01/02)

- 音源:SD 卡 `/music` 下 MP3/AAC/FLAC(P0);网络电台 URL 列表(P1)
- 界面:封面、曲名/歌手、进度条、播放/暂停、上一首/下一首、随机/循环、播放列表
- 输出:Tab5 内置扬声器外放;骑行有风噪,音量上限需实测,考虑 EQ 提升人声和中频
- 音频焦点:小智说话或导航播报时音乐降到 20%,结束后恢复
- 记忆:重启后恢复上次曲目和播放位置

### 2.5 游戏(GAME-01)

- 内置 2–3 款 LVGL 触屏小游戏(2048、贪吃蛇等),单局时间短
- 不做模拟器
- 安全限制:GPS 速度 > 3 km/h 禁止进入游戏,正在运行的游戏暂停并提示

### 2.6 网络与 BLE(NET-01、BLE-01)

- Wi-Fi:经 C6 协处理器(ESP-Hosted)连 2.4GHz 热点,最多保存 5 个网络,按优先级自动重连;默认连手机热点
- BLE(P1):扫描、配对、管理设备;首期支持 BLE 车把遥控器 / 媒体按键(播放、切歌、唤醒小智)
- 不做:经典蓝牙相关的一切功能

### 2.7 设置(SET-01)

- 显示:亮度、自动熄屏时间、日/夜主题
- 声音:主音量、音乐与语音各自的音量、扬声器/耳机输出
- 网络:Wi-Fi 列表、BLE 设备列表
- 小智:服务地址、唤醒词开关、设备激活状态
- 导航:GPS 状态(卫星数、精度)、地图数据目录
- 系统:版本号、OTA 检查升级、存储空间、恢复出厂设置

## 3. 交互与 UI 规范

| 项 | 要求 |
| --- | --- |
| 屏幕 | 全局横屏 1280×720;白天高对比浅色主题为默认,背光 100%;夜间深色,背光 40% |
| 布局 | 状态栏高 48px;Dock 宽 120px;内容区约 1160×672 |
| 触控 | 最小目标 96×96px,相邻间距 ≥ 24px |
| 字号 | 正文 ≥ 28px;导航距离、转向、速度 ≥ 56px |
| 步数 | 常用操作两步以内可达,或一句语音可达 |
| 动效 | 不用全屏闪烁;切页动画 ≤ 250ms |
| 反馈 | 每次触控有按下态;小智聆听/思考/说话三态在浮层和状态栏同步显示 |
| 错误 | 顶部 Toast(网络断开、GPS 丢失、SD 卡未插),3 秒自动消失 |

### 骑行安全规则(SAFE)

| 编号 | 规则 |
| --- | --- |
| SAFE-01 | GPS 速度 > 3 km/h 时禁用游戏、键盘输入(Wi-Fi 密码、搜索)和长列表浏览,引导改用语音或 BLE 按键 |
| SAFE-02 | 导航页骑行中只显示转向箭头、距离、速度三项大字信息 |
| SAFE-03 | 小智浮层不得完全遮挡导航 |
| SAFE-04 | `open_app(game)` 在骑行中返回拒绝,小智口头说明原因 |

## 4. 小智 MCP 工具定义

工具名统一 `self.<模块>.<动作>`。每个 App 启动时向小智 Agent 注册自己的工具。

| 工具名 | 参数 | 作用 | 示例语句 | 优先级 |
| --- | --- | --- | --- | --- |
| self.system.open_app | app: navi / music / game / settings / home | 打开 App 或回桌面 | 「打开音乐」「回到桌面」 | P0 |
| self.system.set_volume | level: 0–100 | 设置主音量 | 「音量调到 60」 | P0 |
| self.system.set_brightness | level: 0–100 | 设置亮度 | 「屏幕亮一点」 | P0 |
| self.system.get_status | 无 | 返回网络、GPS、电量、存储状态 | 「还剩多少电」 | P0 |
| self.navi.get_location | 无 | 经纬度、速度、航向 | 「我现在在哪」 | P0 |
| self.navi.get_ride_stats | 无 | 本次骑行里程、时长、平均速度 | 「骑了多远了」 | P0 |
| self.navi.zoom | delta: -3 到 +3 | 地图缩放 | 「地图放大」 | P0 |
| self.navi.set_favorite | name: home / work 等 | 当前位置存为收藏点 | 「把这里设为家」 | P0 |
| self.navi.navigate_to | name 或 lat/lng | 规划并开始导航 | 「导航回家」 | P1 |
| self.navi.stop | 无 | 结束导航 | 「取消导航」 | P1 |
| self.music.play | query?(歌名/歌手) | 播放或搜索本地曲目 | 「放周杰伦的歌」 | P0 |
| self.music.control | action: pause / resume / next / prev / shuffle / repeat | 播放控制 | 「下一首」「暂停」 | P0 |
| self.music.get_now_playing | 无 | 当前曲目 | 「这首歌叫什么」 | P0 |
| self.music.play_radio | station | 播放网络电台 | 「放交通广播」 | P1 |
| self.ble.list_devices | 无 | 已配对 BLE 设备 | 「连了哪些设备」 | P1 |

规则:

- 收藏点数据保存在设备本地(NVS/SD 卡),不上传
- 工具失败必须返回明确原因(「GPS 未定位」「SD 卡未插入」),由小智转述

## 5. 非功能需求

首版目标值,需实车测试后校准。

| 类别 | 指标 |
| --- | --- |
| 启动 | 上电到桌面可用 ≤ 5 秒;到小智可唤醒 ≤ 10 秒(含联网) |
| 流畅度 | 桌面和列表滑动 ≥ 30 fps;地图拖动 ≥ 20 fps,瓦片缺失先画占位图,不卡 UI |
| 语音 | 唤醒响应 ≤ 500ms;骑行风噪下唤醒率不低于静止时的 70% |
| 内存 | 32MB PSRAM 预算:帧缓冲约 2×1.76MiB、地图瓦片缓存 6MB(48 槽)起、必要时 8MB(64 槽)、音频缓冲 ≤ 2MB、小游戏按需加载并释放 |
| 存储 | 16MB Flash 放双 OTA 分区和资源;地图、音乐放 microSD(≥32GB、Class 10) |
| 定位 | UART 115200,刷新 1–10Hz 可配;定位丢失 3 秒内状态栏提示;GPS 无电(5V 使能失败)与无信号要分开提示 |
| 续航 | NP-F550(14.8Wh,官方约 6 小时 @50% 亮度、Wi-Fi 开)或充电宝 5V;100% 亮度 + GPS + 音频下连续骑行导航 + 音乐 ≥ 3 小时(待实测);低电量降背光并提示,在电池接近 6V 保护线之前安全关机;关机状态不充电 |
| 防护 | 防雨、防震;防水壳或防雨罩;防止 microSD 和 GPS 线颠簸松脱 |
| 温度 | 官方工作温度 0–40°C;暴晒过热时自动降背光并提示,低温时提示性能下降 |
| 可靠性 | 看门狗 + 崩溃日志写 SD;C6 失联自动重置并重连;断电后恢复上次 App 和曲目 |
| 升级 | OTA 升级 P4 主固件,并经 ESP-Hosted 升级 C6 固件;失败自动回滚 |
| 隐私 | 位置、收藏点只存本地;麦克风只在唤醒后上传语音 |
